# AutoAI — умный подбор автомобиля

## Что внутри
- Node.js + Express сервер
- OpenAI API на серверной стороне
- .env для API-ключа
- чат, который извлекает критерии запроса
- подбор только из локального каталога cars.js
- карточки с галереей фотографий
- адаптивный интерфейс

## Запуск на Windows
1. Установи Node.js LTS с https://nodejs.org/
2. Открой папку AutoAI в VS Code.
3. Открой Terminal → New Terminal.
4. Выполни: `npm install`
5. Скопируй `.env.example` в файл `.env`.
6. Открой `.env` и укажи свой ключ: `OPENAI_API_KEY=твой_ключ`
7. Запусти: `npm start`
8. Открой в браузере: http://localhost:3000

Если PowerShell блокирует npm.ps1, не меняй системную политику безопасности. В терминале VS Code выбери Command Prompt (cmd) через стрелку рядом с плюсом, затем снова выполни команды. Также можно выполнять `npm.cmd install` и `npm.cmd start`.

## API
Нужен отдельный ключ OpenAI API и доступный баланс/лимит API. Подписка ChatGPT не включает автоматически оплату API. Создать ключ можно в панели OpenAI Platform.

## Фото
Положи фотографии из старого проекта в `public/images/`, сохранив названия из cars.js, например `Camry-1.jpg`, `Camry-2.jpg`, `RAV4-1.jpg`. Если фотографий нет, карточки покажут заглушку.

## Данные
Цены и годы в `cars.js` — демонстрационные данные исходного учебного проекта. Перед реальным использованием обнови их по проверенным объявлениям. Не считай их текущими рыночными предложениями.
